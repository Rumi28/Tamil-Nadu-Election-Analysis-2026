# Tamil-Nadu-Election-Analysis-2026
A storytelling-focused analysis of the 2026 Tamil Nadu Assembly Election using official ECI datasets.
# Reproduction Steps

## 1. Clone the Repository

```bash
git clone https://github.com/Rumi28/Tamil-Nadu-Election-Analysis-2026.git
```

---

## 2. Open the Project

Open the repository folder in:

* Power BI Desktop
* SQL Server / MySQL
* VS Code or Jupyter Notebook

---

## 3. Dataset Used

The analysis uses:

* tn_2021_results.csv
* tn_2026_results.csv
* constituency_master.csv

All datasets are placed inside the `Data/` folder.

Source:
Election Commission of India (ECI) + Codebasics Starter Pack.

---

## 4. SQL Analysis

Run SQL files from the `SQL_Queries/` folder in the following order:

1. winners_2021.sql
2. winners_2026.sql
3. ranked_2021.sql
4. ranked_2026.sql
5. Party.sql
6. Margin.sql

These queries generate:

* constituency winners
* ranking tables
* party-wise analysis
* margin analysis

---

## 5. Power BI Dashboard

Open: https://app.powerbi.com/groups/me/reports/47091536-f4c6-49ee-b27f-8ef37c4fc774?pbi_source=desktop



If visuals do not load automatically:

* refresh data sources
* reconnect CSV files from the `Data/` folder
